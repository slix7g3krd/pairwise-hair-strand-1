# pairwise-hair-strand

角色转身时发梢边缘一圈发黑，换成短 groom 后发根直接穿出头皮：毛发渲染按固定切线，发根变换没有跟随骨骼；深度预pass 只写不透明片，透明发丝排序错乱；Kajiya 高光按光源方向算，第二个光源把发丝照成塑料；发丝 Alpha 测试阈值固定，MSAA 下边缘锯齿；groom 切换时 LOD 层级没有重映射，发根和发梢错位；风力模拟在 CPU 上按固定子步，低帧率下发丝抖散；发丝阴影只投到主光，背光发根浮空；毛发密度图采样用了不同 UV，发缝出现黑块；相机拉近后发丝几何放大，深度偏移不够产生自遮挡；多角色共用一张发丝排序缓冲，切换角色串发；头发与帽子碰撞只做球体，帽檐穿发；异步模拟读上一帧骨骼，快速转头时发根滞后；毛发材质在 HDR 下高光溢出，边缘烧白。render/hair_strand.py 是核心，tests/test_hair_strand.py 15个红。要修的是：发根骨骼；深度预pass；双光高光；Alpha 阈值；LOD 映射；风场子步；背光阴影；密度 UV；深度偏移；排序隔离；帽子碰撞；异步骨骼；HDR 高光。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
